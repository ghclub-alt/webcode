# CodeMaster

한국어 프로그래밍 학습 웹앱. 진입점은 **index.html**이며 CSS, JavaScript, 기본 강의가 모두 포함되어 있습니다. 별도 빌드나 npm 의존성 설치가 필요 없습니다.

## 실행 (Windows 포함)

Python 3을 설치한 Windows에서 프로젝트 폴더로 이동한 뒤:

```powershell
py -m http.server 8081 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8081`의 index.html을 엽니다. Linux/macOS에서는 `python3 -m http.server 8081 --bind 127.0.0.1`을 사용합니다. 종료는 Ctrl+C입니다. 파일을 직접 열 수도 있지만 HTTP 실행을 권장합니다. 브라우저별 file:// 저장소·Worker 제한이 다릅니다.

기본 강의, 편집, JavaScript, HTML/CSS, 기록 저장은 인터넷 없이 작동합니다. 기록은 해당 브라우저/출처의 localStorage에 저장됩니다. 포트·브라우저를 바꾸면 별도 기록으로 보일 수 있습니다. 시크릿 모드에서는 영구 보관되지 않을 수 있으므로 설정에서 JSON을 내보내세요.

## 실제 실행 환경

| 언어 | 방식 | 요구 사항 |
| --- | --- | --- |
| JavaScript | 일회용 Web Worker | 오프라인, input()으로 표준 입력 읽기, DOM 접근 없음 |
| HTML/CSS | sandbox iframe | 오프라인, 스크립트/네트워크/폼 제출 차단, CSS는 샘플 문서에 적용 |
| Python | Pyodide 0.27.7 (WASM) | 인터넷 및 cdn.jsdelivr.net 접근, 표준 라이브러리만, Worker 실행 |
| SQL | sql.js 1.13.0 (SQLite WASM) | 인터넷 및 cdn.jsdelivr.net 접근, 실행마다 새 메모리 DB |
| TypeScript | TypeScript 5.7.3 변환 후 JS Worker | 인터넷 및 cdn.jsdelivr.net 접근, 문법 진단 제공, 전체 타입 검사 제외 |
| C / C++ / Java / C# / Go / Rust | 독립적인 remoteExecute 어댑터 | 사용자가 운영하는 안전한 실행 서버 필요; 미연결 시 실행 불가 안내 |

외부 라이브러리는 실행 요청 시에만 로드합니다. 기본 강의를 읽는 데 외부 요청이 필요하지 않습니다. Python 임의 패키지 설치, 사용자 파일 업로드, 브라우저 밖 파일 접근은 지원하지 않습니다. 최초 라이브러리 준비는 60초, 사용자 코드 실행은 10초 제한입니다. 출력은 최대 64KB이며 중지 버튼은 로컬 Worker를 종료합니다. Python 런타임은 실행마다 재생성되므로 반복 채점 시 재초기화 비용이 있습니다.

Worker는 UI 정지 방지용 실행 구획이며 적대적 코드를 위한 완전한 보안 경계가 아닙니다. 네트워크 API를 제거하지만 강력한 보안 격리나 정밀한 메모리 제한을 보장하지 않습니다. 자신의 학습 코드만 실행하세요. 신뢰할 수 없는 다중 사용자 서비스 배포에는 별도 출처·CSP·격리 서버·인증·속도 제한이 필요합니다.

## 실행 서버 연동 계약

**실행 서버는 제공하거나 실행하지 않습니다.** 서버가 없는 언어의 결과를 생성하지 않습니다. 설정에서 신뢰할 수 있는 HTTPS URL을 등록하면 다음 JSON을 POST합니다:

```json
{"language":"c","code":"...","stdin":"10\n20","timeout_ms":5000}
```

정상 응답:

```json
{"stdout":"30\n","stderr":"","exitCode":0}
```

실패 응답은 `error` 또는 0이 아닌 `exitCode`와 `stderr`를 사용합니다. CORS는 웹앱의 실제 출처만 허용해야 합니다. 클라이언트 요청은 12초 후 취소되지만 서버는 반드시 독립적으로 작업을 종료해야 합니다. 클라이언트 중지는 원격 작업을 강제 종료하지 않으며 결과만 무시합니다. API 키를 HTML이나 URL에 넣지 마세요.

서버 운영자는 임의 코드를 호스트 프로세스에서 직접 실행하지 않아야 합니다. 작업마다 rootless 컨테이너 또는 microVM, 읽기 전용 루트 파일시스템, 비권한 사용자, 네트워크 차단, CPU/메모리/PID/출력/파일 크기 제한, 프로세스 전체 시간 제한과 작업 후 폐기를 구현해야 합니다. 이 계약만으로 안전한 서버가 만들어지지는 않습니다.

## 제공 범위와 한계

- 12개 언어에 6단계/7개 강의 화면. **Python·C는 설명과 서로 다른 실행 예제 제공**, 나머지 10개는 입문 실습과 심화 학습 주제 안내 수준입니다. 완성된 전문 교육 과정이 아닙니다.
- 코드 입력, 기본 토큰 강조, 줄 번호, Tab/자동 들여쓰기/괄호 닫기, 100단계 실행 취소, 검색, 수동 호출 완성(Ctrl+Space), 복사, 초기화, 다운로드, 자동 저장. 언어 서버 수준의 분석·자동 완성은 아닙니다.
- Python/C 두 정수 합 문제: 정상·0·음수 3개 테스트의 실행 결과 비교. 나머지 출력 문제는 1개 테스트. 숨김 테스트의 정답은 공개하지 않습니다. 서버 미연결 또는 런타임 오류는 오답 제출로 기록하지 않습니다.
- 오류 원문과 주요 오류 유형별 도움말. Python traceback 등의 원본 줄 위치는 표시되지만 편집기 내 오류 줄 강조/완전한 원인 분석은 미구현입니다.
- 진도, 정답률, 제출 횟수, 활성 화면 학습 시간, 북마크, 오답 복습, 최근 단원, 파일별 코드, JSON 백업/복원. 목표는 분 단위 설정이며 일별 시간 이력/연속 학습일은 미구현입니다.
- 자유 실습 파일은 독립 실행합니다. 다중 파일 import/링크/빌드는 미구현입니다.
- HTML/CSS와 프로젝트는 수동 평가입니다. 프로젝트 주제/개발 순서/시작 예제를 제공하며 완성된 대형 프로젝트 강의, 프로젝트 루브릭 자동 평가, 빈칸·결과 예측·오류 수정 전용 시험, 종합 개념 시험은 미구현입니다.
- 계정·클라우드 동기화·AI 분석·배포용 실행 서버는 미제공입니다.

- 새로고침 후 코드/진도 및 자유 실습 파일 복원: 통과

- SQLite SELECT 실행, TypeScript 변환/출력: 통과

회귀 테스트는 서버가 8081에서 실행 중일 때 `node tests/browser.cjs`로 실행합니다. 테스트용 Node.js와 `playwright-core` 설치가 필요하며 Chromium 경로는 기본 `/usr/bin/chromium`입니다. Windows에서는 테스트 파일의 executablePath를 설치한 Chromium 경로로 수정하세요. 외부 런타임 검증은 네트워크 환경에 따라 별도 재확인이 필요합니다.

### 테스트 도구 설치 예시 (Linux)

앱 실행과 별도로, 테스트 도구만 체크아웃 밖에 설치할 수 있습니다:

```sh
npm install --prefix /tmp/codemaster-test playwright-core@1.64.1
NODE_PATH=/tmp/codemaster-test/node_modules node tests/browser.cjs
NODE_PATH=/tmp/codemaster-test/node_modules node tests/runtimes.cjs
```

Chromium 경로는 `CHROMIUM_PATH` 환경 변수로 지정할 수 있습니다. 외부 런타임 테스트는 `HTTPS_PROXY`가 설정되어 있으면 해당 프록시를 사용합니다. TLS 검증을 비활성화하지 않습니다. 화면 패널은 반응형으로 재배치되며 드래그 크기 조절은 미지원입니다.
